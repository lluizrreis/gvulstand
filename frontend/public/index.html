Integração LDAP / Active Directory

Configure a autenticação corporativa via Active Directory (AD) ou servidor LDAP v3. O uso do LDAP é opcional e pode ser ativado a qualquer momento.

Documentação Oficial (PDF) Carregando status...

Habilitar Autenticação & Consulta LDAP

Ao ativar, usuários cadastrados como Rede / LDAP autenticarão diretamente no domínio corporativo via sAMAccountName, e o sistema consultará o Active Directory para validação e busca de dados.

Autenticação Híbrida & Resiliência

Usuários cadastrados manualmente continuam acessando com usuário e senha locais independentemente do status do LDAP. Administradores locais mantêm acesso ininterrupto.

Vínculo por sAMAccountName

Na Gestão de Usuários, o administrador cadastra contas de rede informando o sAMAccountName, aproveitando nome e e-mail do AD e definindo a role manualmente.

1. Servidor & Conectividade

Nome FQDN ou endereço IP do Domain Controller.
Padrão: 389 (LDAP) ou 636 (LDAPS).
Tempo limite para tentativas de conexão.

2. Usuário de Consulta / Leitura (Bind)

Conta de serviço no AD com permissão de leitura nos objetos de usuário.
Por segurança, a senha é armazenada de forma segura e não é exibida na tela.
Raiz a partir da qual o sistema localizará os usuários corporativos.

3. Mapeamento de Atributos do Active Directory (Avançado)

Configurado com padrões do Microsoft Active Directory
Filtro RFC 2254. {username} é o sAMAccountName.
Identificador do usuário no domínio (sAMAccountName).
displayName ou cn para nome do profissional.
mail ou userPrincipalName.
Recomenda-se realizar o Teste de Conexão antes de salvar a configuração.
